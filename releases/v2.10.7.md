# v2.10.7

## Improvements

- PB8 Backtest now provides the same **1st** and **All** start-date shortcuts as Optimize, using their shared field, lookup lifecycle and backend. **1st** selects the earliest selected market; **All** selects a common start for every selected exchange and coin. Both include PB8 warmup; this does not select a full local data range or change Suite scenario dates (#506).

## Fixes

- Submit date lookups with an explicit JSON Content-Type in both editors and render structured API validation errors as readable messages instead of `[object Object]`.
- Keep the explanatory **1st**/**All** shortcut tooltips in both editors.
- DB Tools user cleanup keeps PBData running and creates full backups from stable read snapshots. Small deletion batches yield to other writers and delete only backed-up, unchanged rows; full user cleanup also resets advanced history scan checkpoints by user/exchange. New or changed account data can remain or arrive again while collection continues.
- Cleanup cancellation and failures report confirmed progress. Attempts with zero committed deletions remove their unused backups; backups protecting completed deletions remain available in Backup Manager. Older remote installations receive an update/restart message before maintenance starts.
